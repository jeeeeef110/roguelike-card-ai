# 遊戲玩法總覽(2026-07-08 沙盒衝刺後・對應實作現狀)

> 本文件描述**已實作並通過測試**的全部玩法(152 項測試)。
> 數值標「待平衡」者為初始值,PC 恢復後以模擬器 A/B 定稿。

---

## 一、遊戲循環總圖

```
【局外】讀取存檔(MetaState:已解鎖卡池、進階紀錄、碎片)
   ↓ 選擇進階等級(0 ~ 已解鎖最高)開始新冒險
【冒險】隨機地圖(10–15 層)爬塔:
   選節點 → 戰鬥/菁英/休息/商店/事件 → 獎勵 → …… → Boss
   ↓ 通關或陣亡
【結算】碎片入帳(雖敗猶得);擊殺 Boss → 稀有卡三選一「永久解鎖」
   → 通關再解鎖下一級進階 → 回到局外,下一輪
```

三層各自的樂趣:戰鬥層是「這回合怎麼打」、冒險層是「這輪怎麼走、build 怎麼組」、局外層是「下一輪會有什麼新東西」。

## 二、戰鬥(核心層)

**回合結構**:回合開始抽 5 張、能量回滿 3、護甲歸零(堅守除外)→ 出牌階段(能量限制內不限張數;**攻擊卡每回合上限 3 張**,破限卡可解除)→ 回合結束手牌全棄 → 敵人執行已公開的意圖 → 下一回合。牌庫抽完時棄牌堆洗回。

**狀態效果(5 種)**:護甲(擋等量傷害,回合始歸零)、力量(每層攻擊 +1,永久)、易傷(受傷 ×1.5,逐回合遞減)、虛弱(造成傷害 −25%,逐回合遞減)、中毒(回合始扣層數等量 HP、無視護甲,逐回合 −1)。

**意圖制**:敵人不出牌,每回合公開宣告下一步(攻擊 X / 防禦 / 上毒……),玩家看預告做決策——整個戰鬥層的決策核心。

**藥水(上限 3 瓶)**:戰鬥中**免費動作**(不耗能量、不佔攻擊上限)。五種:火焰瓶(傷 10)、治療(回 12)、力量藥劑(+2)、鐵壁藥水(甲 12)、劇毒瓶(毒 5)。戰後 35% 掉落、商店有售。是「危急翻盤」的記憶點來源。

## 三、卡牌與 Build(27 張)

**起始牌組**:打擊 ×5、防禦 ×4、狂暴 ×1。
**稀有度**:起始 / 普通(獎勵權重 3)/ 稀有(權重 1,build 定義卡)。
**升級**:鍛造(費用 −1,休息點或鐵匠)、淬毒(毒值 +1,毒藥商)。

**五條 build 路線**(engine → piece → payoff):

| 流派 | 核心卡 | 打法一句話 | 剋 | 怕 |
|------|--------|-----------|----|----|
| 毒流 | 毒刃/猛毒 → 鐵壁 → **引爆**(毒×2 傷並清空) | 疊毒拖時間,抓時機引爆 | 石像兵、狂戰士 | 速攻局、吸血蝠 |
| 力量連擊 | 蓄力 → 連擊/撕裂 → **亂舞**(2×4) | 先蓄力,多段收割 | Boss 搶血 | 前期弱、**狂戰士** |
| 反甲 | 鐵壁/堅守 → 盾擊 → **反甲擊**(傷=護甲) | 疊甲轉傷 | 巨鼠、**吸血蝠** | 狂暴計時 |
| 易傷爆發 | 重擊 → 順勢斬 → **制裁**(每層易傷+4) | 開易傷窗口塞爆發 | 高 HP 單體 | 費用重 |
| 節奏 | 蓄勢/充能 → 兵法/透支 → 背水 | 資源預支與交換 | 巨鼠(打斷) | 續戰差 |

## 四、敵人(每隻一道謎題)

| 敵人 | HP | 行為 | 謎題(玩家要學會的事) |
|------|----|------|------------------------|
| 巨鼠 | 42 | 60% 攻 6 / 40% 蓄力→攻 12 | 蓄力期間打 ≥8 傷可**打斷**:爆發 vs 疊甲硬吃 |
| 毒蛛 | 33 | 攻+毒/毒/甲;每 3 回合**織網** | 織網後攻擊卡費 +1:規劃卡序、技能回合 |
| 石像兵 | 60 | 循環 甲8→攻9→攻9;每回合被動 +3 甲、**護甲不歸零** | 破甲與毒(無視護甲)的價值 |
| 吸血蝠 | 38待平衡 | 70% 吸血攻 7 / 30% 攻+毒 | 吸血量=**實際**造成傷害:全擋=吸不到,反甲剋星;低甲則是競速 |
| 狂戰士 | 52待平衡 | 循環 攻8→攻8→甲10;**每受一擊力量 +1**(毒不算) | 反連擊:多段小刀餵養牠,單發重擊與毒才是解 |

**Boss 腐化騎士(HP 90)**:每 3 回合力量 +1(狂暴計時,反龜縮)→ HP <50% 切換二階段:單發重擊 9 變 5×3 連擊(重擊怕高甲、連擊怕易傷/虛弱)——中途必須換防禦策略。

## 五、地圖與節點(冒險層)

**結構**:分層 DAG,10–15 層(參數化)、每層 2–4 節點、沿連線往上走。
**硬約束**:第 1 層必為小怪、Boss 前一層必為休息點、商店不連續、**菁英第 4 層起**。
**深度分池**:第 2–4 層只出巨鼠/毒蛛(入門),第 5 層起全池——前後段手感不同。

**節點型別**:
- **戰鬥**:勝 → 25 金 + 三選一加卡(可跳過)+ 35% 掉藥水
- **菁英**(石像兵/吸血蝠/狂戰士強化版:HP ×1.35 + 起手力量 1):勝 → 45 金 + **三選一全稀有**——每輪的「build 定義時刻」,繞不繞路打它是地圖層核心抉擇
- **休息**:二選一——回血 30% **或** 鍛造一張卡(保命 vs 變強)
- **商店**:賣 1 張稀有卡(65 金)、1 瓶藥水(25 金)、刪卡服務(50 金)——花錢定向湊 build
- **事件(問號)**:三種,核心都是「要不要正式轉流派」:
  鐵匠(永久鍛造一張)/ 毒藥商(全毒卡 +1,代價失去一張非毒攻擊卡;或拿試用毒刃)/ 老戰士(一張防禦換隨機攻擊卡)

## 六、局外養成(收集軸 × 挑戰軸)

**設計鐵律:解鎖「變化」,不解鎖「變強」**(永久數值加成會污染平衡數據,已廢除)。

- **收集軸**:稀有卡 7 張,起始依存檔 seed 解鎖 3 張(每個玩家起點不同)。
  **擊殺 Boss → 未解鎖稀有卡抽 3 選 1 永久入池**——每次解鎖都是影響之後幾十輪的決策,4 次擊殺全解鎖。
- **挑戰軸(進階等級)**:通關進階 N 解鎖 N+1,每級全體敵人 HP +10%——重玩軸,與收集互不干擾。
- **碎片**:每輪結算 = 層數×2 + 菁英×5 + Boss+20,**輸了也有**;用途(解鎖新角色等)為後續擴充。
- **存檔**:單一 JSON、含版本號、孤兒卡 id 防呆。

## 七、遊戲內 AI(玩家看得到的部分)

- **出牌建議**:MCTS 代理(啟發式 rollout)可即時顯示「AI 認為的最佳動作與勝率估計」——單機遊戲裡內建一個會思考的教練。

## 八、一輪冒險的實際體驗(把上面全部串起來)

開局:讀檔,你的卡池有 3 張稀有(這個存檔開的是引爆、回收、破限)→ 選進階 1(上輪通關解鎖的)→ 地圖生成,你看到第 5 層有隻菁英狂戰士,而你想走連擊流——**繞路,還是換 build?** → 前 3 層小怪熱身,撿了張毒刃和一瓶火焰瓶 → 問號遇到毒藥商:全押毒流的機會來了,犧牲一張重擊,毒卡全部 +1 → 第 6 層繞去打菁英石像兵(毒無視護甲,正是主場),贏,三張稀有裡出現引爆——毒流成型 → 休息點:血還有六成,**賭一把選鍛造**,毒刃變 0 費 → Boss 戰:狂暴計時逼你別拖,疊毒到 14 層,牠進二階段連擊前一回合,**引爆 28 傷收頭** → 結算:碎片 +45,三選一解鎖了亂舞——**下一輪,換連擊流試試?**

這一段裡的每個粗體,都是一個系統存在的理由。
